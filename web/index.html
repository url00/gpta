About

GPTA is a small receipt printer appliance. A background server gathers data from pluggable modules on a schedule, lays it out as receipts, and prints them on a thermal printer. This page is its local console.

Use the Instant tab to print pasted text once, for example from a phone. Modules start disabled. Enable and configure them on the Modules tab, and set up the printer on the Printer tab.

        Public address

        Where a phone reaches this server, e.g. https://gpta.example.com. Printed QR selection codes link to it, so modules cannot make selection lists until it is set.

        QR selection test

        Makes a sample list the way a module does: each item has a code that, when scanned, tells this server which item was chosen. Scanning a test code prints a short confirmation. A second scan of the same code within 30 seconds is ignored.
