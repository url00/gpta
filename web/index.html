About

GPTA is a small receipt printer appliance. A background server gathers data from pluggable modules on a schedule, lays it out as receipts, and prints them on a thermal printer. This page is its local console.

Modules start disabled. Enable and configure them on the Modules tab, and set up the printer on the Printer tab.
