GPTA Privacy Policy

GPTA is a personal, self-hosted program that prints short receipts on a thermal printer. This instance is run by one person for their own use. It is not a public service and has no user accounts.

Google data GPTA accesses

If its owner signs in with Google, GPTA reads, and only reads:

  • that account's Google Tasks (task lists and tasks: titles, notes, due dates and completion status), with the scope https://www.googleapis.com/auth/tasks.readonly;
  • that account's Google Calendar (the calendar list and the current day's events: titles, times, locations and the owner's own reply), with the scope https://www.googleapis.com/auth/calendar.readonly.

It cannot create, change or delete tasks or events, and it requests no other Google data.

How the data is used

Tasks and the day's events are fetched to print a task list and a daily itinerary on the owner's printer, and to show the same receipts in the owner's GPTA console. That is the only use.

Storage

Everything is stored on the owner's own machine: the OAuth client details and refresh token that keep the sign-in working, the most recent task list and itinerary, and a fingerprint of each used to detect changes. Each new receipt replaces the previous one.

Sharing

Google data is not shared with, sold to, or transferred to anyone. It is not used for advertising, analytics, or training AI models. It leaves the machine only as requests to Google's own APIs.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting GPTA's data directory removes the stored sign-in, task and calendar data.

Contact

Questions go to the operator of this GPTA instance.
